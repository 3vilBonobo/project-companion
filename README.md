# Project Companion

Project Companion is a calm, offline-first application that helps people finish meaningful personal projects without being overwhelmed. It presents one recommended action at a time and treats rest, pauses, and missed days as normal—not as failure.

This repository contains the functional v0.2 offline product foundation built with Angular 20, standalone components, Signals, Ionic 8, and Capacitor.

## Product principles

- One small, meaningful task at a time.
- No dashboards, streak pressure, guilt, or noisy analytics.
- AI will simplify planning later; it will not take agency away from the user.
- Every primary screen answers one question: “What should I do next?”
- Local and functional without an account, server, or network connection.

## Architecture

The application uses feature-first, standalone Angular architecture:

- `core/models` contains domain interfaces (`Project`, `Task`, `Progress`, and `Settings`).
- `core/storage` provides the only persistence boundary. Components never access `localStorage`.
- `core/services` owns project mutations, progress calculation, and today’s recommendation logic.
- `shared/components` contains small presentational building blocks.
- `features` contains lazy-loaded routed pages.

Application state lives in Angular Signals. `ProjectService` owns the project collection and persists every mutation through `StorageService`. `TodaysTaskService` derives the first incomplete ordered task from the user’s projects. `ProgressService` remains stateless and calculates progress from domain data.

This boundary makes a future move from LocalStorage to IndexedDB, SQLite, or a synced repository possible without rewriting components.

## Design decisions

- **Today is the default route.** Opening the app immediately reveals the smallest useful action.
- **A single task card dominates the page.** There is no competing navigation, task backlog, or metric wall.
- **Language is non-judgmental.** Copy avoids deadlines and failure states.
- **The visual system is quiet.** Warm neutral surfaces, muted sage accents, wide spacing, rounded geometry, and minimal elevation create a soft Ionic/iOS feel.
- **Project detail is restrained.** The full task plan is available only after deliberately opening a project.
- **Editing is complete but tucked away.** Projects and steps can be edited, reordered, completed, reopened, and removed without crowding the Today screen.
- **Backup stays user-controlled.** Versioned JSON export and validated import provide portability without an account or cloud service.
- **AI planning stays transparent.** A user can ask ChatGPT for a plan, inspect the JSON, and import it locally. No project data is sent from the app.
- **Sample content is seeded once.** A new installation immediately has a useful path to explore, while data remains fully local.
- **Strict TypeScript and OnPush rendering** provide a reliable foundation for growth.

## Run locally

Requirements: Node.js 20.19+ or 22.12+ and npm.

```bash
npm install
npx ionic serve
```

The browser opens at `http://localhost:8100` and redirects directly to `/today`.

Build the production web bundle:

```bash
npm run build
```

The output is written to `www/`.

## Import a project plan generated by ChatGPT

Project Companion can create a complete project from a JSON file, or append generated steps to an existing project.

1. On **Projects**, choose **Copy ChatGPT prompt**.
2. Paste the prompt into ChatGPT and replace the final placeholder with your project description.
3. Save ChatGPT's JSON-only response as a `.json` file.
4. Choose **Import AI plan** to create a new project, or open a project and choose **Import steps** to append the tasks.
5. Review the number of steps and confirm the import.

The app accepts this versioned format:

```json
{
  "schemaVersion": 1,
  "title": "Create a Small Balcony Garden",
  "description": "Build it one small choice at a time.",
  "tasks": [
    {
      "title": "Measure the sunny space",
      "description": "Note the dimensions and hours of sunlight.",
      "estimatedMinutes": 10,
      "difficulty": "gentle",
      "notes": ""
    }
  ]
}
```

`description`, `estimatedMinutes`, `difficulty`, and `notes` are optional on tasks. Missing values default to an empty description, 15 minutes, `gentle`, and empty notes. Difficulty must be `gentle`, `focused`, or `stretch`. Imports are limited to 200 tasks and 1 MB. See [the complete example](public/examples/project-plan.example.json).

## Native setup

Capacitor configuration is included. After installing the platform package you need, build and sync:

```bash
npm install @capacitor/ios @capacitor/android
npx cap add ios       # or: npx cap add android
npm run build
npx cap sync
```

Native projects are intentionally not committed in this foundation so each platform can be initialized with its current toolchain.

## Persistence and privacy

Projects and preferences are stored under versioned LocalStorage keys on the current device. There is no authentication, API, telemetry, Firebase integration, or cloud sync. The Settings page can export a readable JSON backup and restore a validated v1 backup later.
